# MoviePilot-Plugins

> [!NOTE]
> MoviePilot 第三方插件仓库，由 [redwebsite](https://github.com/redwebsite) 维护

## 插件列表

| 插件 | 版本 | 说明 |
|------|------|------|
| [MediaWarp](https://github.com/redwebsite/MoviePilot-Plugins/tree/main/plugins.v2/mediawarp) | 1.3 | EmbyServer/Jellyfin 中间件：优化播放 Strm 文件、自定义前端样式、自定义允许访问客户端、嵌入脚本 |
| [P115StrgmSub](https://github.com/redwebsite/MoviePilot-Plugins/tree/main/plugins.v2/p115strgmsub) | 1.7.4 | 115网盘订阅追更魔改版，内置事件驱动洗版通知、屏蔽时段调度、评分拦截系统、MP 规则组管理 |
| [Doc911Subscribe](https://github.com/redwebsite/MoviePilot-Plugins/tree/main/plugins.v2/doc911subscribe) | 1.0.01 | 每天自动扫描金山文档，将在播新剧添加到 MP 订阅，TMDB 识别失败时发送通知提醒 |
| [LibraryScraperEnhanced](https://github.com/redwebsite/MoviePilot-Plugins/tree/main/plugins.v2/libraryscraper_enhanced) | 2.1.3-enhanced | 媒体库刮削增强版，支持多线程并行刮削，补齐缺失元数据和图片 |

## 安装

在 MoviePilot 的插件市场中添加本仓库地址：

```
https://github.com/redwebsite/MoviePilot-Plugins
```
