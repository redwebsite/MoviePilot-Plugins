# MoviePilot-Plugins

> [!NOTE]
> MoviePilot 第三方插件仓库（仅维护 MediaWarp 插件）

本仓库仅保留 [MediaWarp](https://github.com/AkimioJR/MediaWarp) 插件，并与原作者仓库保持同步。

## 插件列表

- [MediaWarp](https://github.com/RedWebsite/MoviePilot-Plugins/tree/main/plugins.v2/mediawarp)：EmbyServer/Jellyfin 中间件：优化播放 Strm 文件、自定义前端样式、自定义允许访问客户端、嵌入脚本。

## 安装

在 MoviePilot 的插件市场中添加本仓库地址：

```
https://github.com/RedWebsite/MoviePilot-Plugins
```
